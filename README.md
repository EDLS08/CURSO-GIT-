# Git and HTML Learning Repository

A small practice repository used to explore Git, GitHub, and basic HTML page structure. It contains simple standalone pages and an image asset from the original learning exercises.

## Pages

- `index.html` — introductory page about studying Git and GitHub.
- `contato.html` — contact-page form exercise.
- `galeria.html` — basic gallery page.
- `login.html` — login-form markup exercise.
- `servicos.html` — simple content and image page.

## Run locally

Open any HTML file directly in a browser. No build step or package installation is required.

## Project status

This repository is maintained as a learning record. The forms are static HTML exercises and are not connected to a backend.
