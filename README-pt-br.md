# Repositório de Estudos de Git e HTML

Repositório simples de prática para explorar Git, GitHub e a estrutura básica de páginas HTML. Contém páginas independentes e um arquivo de imagem dos exercícios originais.

## Páginas

- `index.html` — página introdutória sobre o estudo de Git e GitHub.
- `contato.html` — exercício de formulário de contato.
- `galeria.html` — página básica de galeria.
- `login.html` — exercício de marcação de formulário de login.
- `servicos.html` — página simples com conteúdo e imagem.

## Como executar

Abra qualquer arquivo HTML diretamente no navegador. Não é necessário processo de build nem instalação de pacotes.

## Estado do projeto

Este repositório é mantido como registro de aprendizado. Os formulários são exercícios de HTML estático e não estão conectados a um back-end.
